# 자린고비 — 챌린지형 저축 게이미피케이션 앱 마스터 기획서

## 1. 프로젝트 개요
- **제작 주제**: 챌린지형 저축 게이미피케이션 앱 (앱 이름: 자린고비)
- **타겟 고객**: 일상에서 소소하게 빠져나가는 돈을 아끼고 싶은 10~30대 (MZ세대)
- **제작 의도 및 차별점**
  - **경제적 니즈 + 재미**: 기존의 형식적/계산적 가계부나 단순 앱테크(10~1,000원의 소액 리워드)의 한계를 넘어, 게이미피케이션 시스템을 도입해 게임하듯 즐거운 저축 습관 형성.
  - **소비 대체 효과**: 저축으로 모은 게임 내 재화를 통해 귀엽고 꼬질한(힙한) '자린이' 캐릭터의 옷을 입히고 방을 꾸미는 대리 만족 제공 (MZ세대 취향 저격).
  - **동기 부여**: 명확한 상징적 목표 액수를 시각적으로 보여주어 의욕을 잃지 않게 하고, 유저 간 정보를 공유할 수 있는 커뮤니티(수다방)를 통해 지속성 부여.

## 3. 핵심 플로우 및 페이지

### 3.1 로그인 / 모드 선택
- **로그인**: 상단 '자린 고비' + #ABBCA2 박스에 '밧줄에 묶인 굴비' 아이콘. 소셜 로그인, 비밀번호 폼(눈 모양 토글), 둥근 모서리 로그인 버튼, '비밀번호를 잊으셨나요?' 링크.
- **노말 모드(NORMAL)**: #ABBCA2 배경, '10' 금화를 안은 자린이. **30일 / 30만원** (매일 1만원).
- **하드 모드(HARD)**: #617C53 배경, 지갑에서 고개 내민 자린이. **30일 / 100만원** (매일 3~4만원). 정확히 100만원 맞추기 위한 **'추가 절약' 직접 등록** 기능 필수.

### 3.2 메인 화면
- **양심 시스템**: 하트 3개(#F49496). 클릭 시 딤+팝업 → "당신의 양심 지키시겠습니까?" + 거대 하트 → [취소] / [양심 삭제(#617C53)].
- **D-day & 금액**: D-30부터 1일씩 차감. 중앙에 누적 금액(0 → 30/100만원).
- **MY 버튼**(우상단): 캐릭터 얼굴 → 마이페이지.
- **캐릭터 룸**: 천장 굴비(밧줄), 문/창문 등 방 내부, 중앙 자린이(상점 구매 + 옷장 착용 실시간 반영).
- **오늘의 절약 미션** (하단)
  - 미션 세팅 팝업: 랜덤 목표 금액에 맞춘 미션 리스트(일러스트·미션명·금액·코랄 핑크 난이도 태그).
  - 변경 팝업: [변경하기 →] 클릭 → 카테고리 탭(식비/여가/충동/통장) → 대체 미션 선택.
  - 확정: 큼직한 [챌린지 확정하기] 버튼.
  - 확정 후: 오늘 미션 + [양심 깎기] + [카메라(인증) 이어가기].
- **하단 네비**: 우하단 [상점] 플로팅, 최하단 [수다방]/[챌린지(#617C53 활성)]/[카메라].

### 3.3 상점 / 옷장
- **상점**: 상단 보유 코인 + 우상단 옷장 버튼. 캐릭터/방 미리보기. 카테고리(전체/사치품/티셔츠/리모델링). 3열 그리드, 미구매는 회색 레이어 + 자물쇠 + 가격(00P).
- **옷장**: MY 타이틀, 좌상단 즐겨찾기 별, 장착 중 '사용 중' 태그. 연한 민트/그린 배경.

### 3.4 수다방 (커뮤니티)
- **리스트**: 상단 굴비 + 가로선. 운영자 지정 주제별 방(편의점 꿀조합, 가성비 레시피, 체험단 꿀팁, 혼놀 취미)이 파스텔 카드 + 일러스트로. [바로가기 →] 버튼.
- **스레드**: 우상단 핑크 스크랩 보관함. 최상단 입력폼(내 프로필·닉네임·"하고 싶은 말이 있나요?"). 피드(타인 프로필·닉네임·본문·우측 북마크).

### 3.5 챌린지 정보
- **리스트**: 상단 카테고리 탭 4개(식비/여가/충동/통장) — 활성 시 #617C53. 가로형 카드(일러스트, 미션명, 핑크 난이도 태그, 짧은 팁, [바로가기 →]).
- **상세**: 둥근 모눈종이 배경. 카테고리 뱃지 + 제목, 기대 절약 효과 + 체크마크 액션 플랜. 최하단 인증샷 가이드(POV 실사 + 2D 자린이 손 합성 예시).

### 3.6 카메라 인증 / 보상
- 카메라 촬영 또는 갤러리 업로드 → 당일 챌린지 완료.
- 인증 즉시: 메인 누적 금액 +(예: 10,000원) + 게임 재화 +(예: 100P).

### 3.7 마이페이지 / 칭호 (공유 최적화)
- 인스타 스토리 사이즈, 찢어진 모눈종이 다이어리 질감.
- 우상단 외부 공유(⍐) + 환경설정(⚙️).
- 프로필: ★ 프레임 안 캐릭터 + 하단 육각형 칭호.
- 우측 정보: 거지탈출 OO일차 / 닉네임(형광펜) / 현재금액 / 목표금액.
- 북마크(스크랩), 코인(상점). 챌린지 O회차(터치 → 상세).
- **RECORD/캘린더**: 1~30일 격자, 인증한 날은 인증샷 썸네일, 미완료는 짙은 회색.
- **칭호 팝업**: 3열 그리드, 헥사곤 일러스트 + 텍스트(홈 바리스타, 배달 킬러 등). 장착 중은 핑크 '적용 중' 태그. 미획득은 검정 불투명 레이어.

### 3.8 챌린지 완료
