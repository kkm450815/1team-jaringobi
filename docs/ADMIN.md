# 자린고비 — 관리자 / 홍보 대시보드 스펙

운영자가 비개발자여도 미션 컨텐츠 편집·푸시 발송·통계 확인이 가능하도록 설계된 별도 웹 어드민의 기능 정의.

스택: **Next.js 14 (App Router) + shadcn/ui + Supabase**, 도메인 `admin.jaringobi.app`.

---

## 1. 메뉴 구조

```
📊 대시보드
   ├─ 핵심 지표 (DAU/WAU/MAU, 신규/잔존)
   ├─ 챌린지 퍼널
   └─ 코호트 리텐션

📝 컨텐츠 관리
   ├─ 일일 미션 템플릿
   ├─ 챌린지 정보 (팁 글)
   ├─ 수다방 토픽
   ├─ 칭호
   └─ 상점 아이템

🛡 모더레이션
   ├─ 신고된 인증샷
   ├─ 신고된 게시글
   └─ 자동 차단 로그

📣 마케팅 / 푸시
   ├─ 푸시 캠페인
   ├─ 인앱 배너 / 팝업
   ├─ 추천 코드 / UTM
   └─ A/B 실험

👥 사용자
   ├─ 검색 / 상세
   └─ 제재 / 차단

⚙️ 설정
   ├─ 운영자 계정
   ├─ 피처 플래그
   └─ 시즌 / 회차 글로벌 설정
```

---

## 2. 대시보드

### 2-1. 핵심 지표 카드 (실시간)
- DAU / WAU / MAU
- 활성 챌린지 수 (노말/하드 분리)
- 오늘 미션 인증 완료율
- 평균 누적 저축액
- 양심 잔여 평균 (3 만점)
- 30일 완주율 (최근 종료 회차)

### 2-2. 챌린지 퍼널
```
가입 → 모드 선택 → D1 미션 확정 → D1 인증 → D7 도달 → D30 완주 → 재참여
```
각 단계별 전환율, 이탈 단계 강조 (Sankey 또는 Funnel 차트).

### 2-3. 코호트 리텐션
- 가입 주차 × D1/D7/D30 잔존
- 모드별·캐릭터 첫 아이템별 비교

### 2-4. 데이터 소스
- 모든 차트는 Supabase의 **materialized view** 기반 (어드민에서 SQL 노출 X)
- 실시간 카드는 view + 60초 캐시
- Amplitude 임베드(iframe)로 심층 분석 채널 제공

## 3. 컨텐츠 관리 (CMS)

> **목표**: 비개발자가 앱 재배포 없이 매일 미션을 갱신할 수 있어야 함.

### 3-1. 일일 미션 템플릿
| 필드 | 타입 | 설명 |
|---|---|---|
| 카테고리 | enum | 식비/여가/충동/통장 |
| 제목 | text | "편의점 안 가기" |
| 금액 | int | 5,000~40,000 |
| 난이도 | enum | EASY/NORMAL/HARD (코랄 핑크 태그) |
| 일러스트 | image | Drag&Drop, Storage 업로드 |
| 모드 호환 | multi | normal / hard |
| 활성 | bool | OFF 시 롤링 제외 |

UI: 테이블 + 인라인 편집, 우측 패널에 "이 미션이 적용된 회차 수" 노출.

### 3-2. 챌린지 정보 (팁 글)
- 카테고리(식비/여가/충동/통장) × 항목
- 모눈종이 배경 마크다운 에디터 (Tiptap)
- 본문: 기대 절약 효과 + 체크리스트 액션 플랜
- 인증샷 가이드 이미지 첨부

### 3-3. 수다방 토픽
- 이름, 테마 컬러, 일러스트
- 노출 순서 드래그
- 비활성 토글

### 3-4. 칭호
- 명칭, 헥사곤 일러스트, 획득 조건(JSON 빌더)
- 예: `{ "type": "complete_mission", "category": "식비", "count": 10 }`

### 3-5. 상점 아이템
- SKU, 카테고리(상의/하의/방/소품), 가격(P), 일러스트, 활성
- 미리보기: 임시 캐릭터에 즉시 적용

## 4. 모더레이션

### 4-1. 신고된 인증샷 큐
| 컬럼 | 내용 |
|---|---|
| 썸네일 | 클릭 → 원본 |
| 사용자 | 닉네임 + 누적 신고 수 |
| 자동 NSFW 점수 | 0.0~1.0 |
| 신고 사유 | enum |
| 액션 | [승인] [반려·코인 회수] [경고] [정지] |

자동 차단(자동 점수 ≥ 0.7)은 별도 로그 탭에 누적.

### 4-2. 신고된 게시글
- 본문 미리보기, 작성자, 신고 횟수
- 일괄 처리(체크박스)

## 5. 마케팅 / 푸시

### 5-1. 푸시 캠페인
- **세그먼트 빌더**
  - 미리 정의: `이탈 위험 (D3 미인증)`, `하드 모드 진행 중`, `완주 직전 (D28)`, `완주 후 미재참여`
  - 커스텀: SQL 기반(어드민이 GUI로 조립)
- **메시지**: 제목/본문/딥링크 URL
- **A/B**: 변형 2개, 비율 슬라이더
- **예약**: KST 시각, 즉시 발송 옵션
- **결과**: 발송수/오픈율/딥링크 클릭/전환(미션 확정)

### 5-2. 인앱 배너 / 팝업
- 메인 화면 상단 또는 모드 선택 후 노출
- 노출 조건(피처 플래그 연동), 스타트/엔드 일정
- 디자인: 미리 정의된 템플릿 3종(이미지·CTA·딥링크)

### 5-3. 추천 코드 / UTM
- 인플루언서별 코드 생성 → `jaringobi.app/r/<code>` 딥링크
- 가입 시 어트리뷰션 → 인플루언서 대시보드(가입수, 완주수)
- 외부 공유 카드(마이페이지/완주 화면)는 자동 UTM 부여

### 5-4. A/B 실험
- 미션 난이도 분포, 코인 지급량, 캐릭터 디폴트 룩
- GrowthBook 임베드 → 결과(전환율 차이, p-value) 시각화

## 6. 사용자 관리

- 검색: 닉네임, 이메일, user_id
- 상세: 회차 이력, 결제(추후), 신고 내역, 디바이스
- 액션: 일시 정지, 영구 차단, 코인 강제 보정(감사 로그 기록)

---

## 7. 설정

### 7-1. 피처 플래그
- 신규 기능 ON/OFF (예: `season_pass_v1`)
- 환경별(dev/staging/prod) 분리

### 7-2. 시즌 / 회차 글로벌
- 노말/하드 목표액 변경 (긴급 운영 가정)
- 일일 미션 자정 롤링 시각

### 7-3. 운영자 계정
- 역할: ADMIN / EDITOR / MODERATOR (RLS로 강제)
- 감사 로그: 누가 언제 무엇을 변경했는지 (`audit_log` 테이블)

## 9. 통계 이벤트 매핑 (Amplitude)

| 이벤트 | 트리거 | 속성 |
|---|---|---|
| `signup_completed` | 가입 성공 | provider |
| `mode_selected` | 모드 선택 | mode |
| `mission_confirmed` | 챌린지 확정 | day_no, category, amount |
| `mission_verified` | 인증 성공 | day_no, latency_ms |
| `heart_consumed` | 양심 차감 | hearts_left |
| `item_purchased` | 상점 구매 | sku, price_p |
| `share_card_generated` | 공유 카드 생성 | round_no |
| `landing_download_clicked` | 랜딩 문서 다운로드 | doc_id |

> 이벤트 이름은 `packages/analytics/events.ts`에 단일 정의 (오타 방지).

## 10. 마케팅 KPI (운영자가 매주 확인)

- **획득**: 신규 가입 / CAC (광고비 / 신규 가입)
- **활성화**: D1 미션 인증율
- **잔존**: D7 / D30 잔존
- **참여**: 회차당 평균 인증일수, 양심 소진율
- **확산**: 외부 공유 카드 클릭→가입 전환율
- **수익(추후)**: 시즌 패스 결제 전환율
